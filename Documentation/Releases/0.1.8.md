# ElderStar 0.1.8

Built-in Render Pipeline / VRChat PC向けパーティクルシェーダーの初回配布版です。
NOVA 3.6.0の標準マテリアル・Prefab参照、シェーダー名、プロパティ、公開Editor APIを維持しています。

## ダウンロードと導入

どちらか一方を導入してください。

- **ElderStar-0.1.8.unitypackage**：Unityで開いて`Import`。本体・説明書・サンプルが`Assets/Nova`に入ります。VRChatプロジェクトにも使えます。
- **me.smizuoch.elderstar-0.1.8.tgz**：`Window > Package Manager > + > Add package from tarball...`から選択。サンプルはPackage Managerの`Built-in Showcase`からImportできます。
- **SHA256SUMS.txt**：配布ファイルのSHA-256チェックサム。

元のNOVA本体との同時導入は避けてください。元のNOVAを同梱した素材は、`Assets > Import Package > ElderStar Effect...`で取り込めます。標準マテリアルの変換は不要です。

Unity 2022.3 LTS以降、Built-in、Windows / Direct3D 11・12が対象です。
VRChatではSDKが指定するUnityバージョンを使用してください。Quest/Android版ではありません。

## 内容

- Particle / UIのUber Unlit・Uber LitとDistortion。
- Flow Map、Flip Book、Dissolve、Rim、Parallax、Emission、Custom Data、最適化シェーダー生成。
- 通常Unity用のカメラ歪み合成、Canvas追加ライト、DepthNormals、環境光補助。
- 日本語の設定表、ElderStarで撮影した作例GIF・Inspector画像、サンプル。

アバターの基本描画には実行時C#を追加する必要はありません。カメラ・Canvas補助コンポーネントは通常Unity用です。

## 検証と制限

配布する両形式をUnity 2022.3.22f1 / 6000.3.23f1の隔離したBuilt-inプロジェクトで導入し、6シェーダーの検索・コンパイル、サンプル実描画、48種類の最適化シェーダー生成を確認しています。

URPの完全互換ではありません。ライト・環境光の入力、複数の歪みの累積、ワールドの深度設定、URP専用C# APIなどに差があります。実機PCVR・最新状態の実クライアント検証は継続中のため、初回はPre-releaseとして配布します。
